#Responsiv webbplats med Figma webbdesign:
- Detta projekt utgår ifrån att göra en Figma prototyp som passar till en responsiv webbplats med sina helhet med semantiska HTML och CSS layout. 
- Syftet med detta är att träna hur man jobbar med Figma och samtidigt anpassa webbplatsen för små och stora skärmar.

 ## Innehåll:
 * Header med logotyp och navigationsmeny
 * Hero sektion med upptäck Norrgläntan
 * intro text 
 * Aktivitetssektion med text och bilder
 * footer med logotyp, kontakter och länkar.
